# Театральная система — версия 1

Учебное приложение Windows Forms для добавления и изменения спектаклей в базе Microsoft Access.

Откройте `TheaterVersion1.sln` в Visual Studio, выберите запускаемым проектом `Theater.Version1` и нажмите F5. Требуются .NET Framework 4.8 и Microsoft Access Database Engine (ACE) x64. База данных: `Database\Театр.accdb`.
